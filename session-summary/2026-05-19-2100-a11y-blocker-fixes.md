## Decisions techniques prises

| Decision | Justification |
|---|---|
| `--color-link` (navy) au lieu de `--color-accent` (teal) pour texte sur fond clair | Teal #67CBC7 = 1.93:1 sur blanc (echec AA). Navy #244882 = 9.7:1 (AAA). |
| `<button>` pour les icones sociales plutot que `<a>` | Pas de liens reels encore. Semantiquement correct, evite navigation parasite. |
| `<span>` pour les arrow-link decoratifs dans les feature cards | Ces fleches ne sont pas des liens fonctionnels, juste des elements visuels. |
| `visually-hidden` h1 pour Contact | La page a deja un h4 titre de formulaire visible. Un h1 visible dupliquerait le contenu. |
| Labels visibles plutot que aria-label sur les inputs Contact | WCAG 3.3.2 recommande les labels visibles. Style compact pour ne pas casser le design. |
| PhoneMockup recoit `t` en prop | Evite d'appeler useTranslations dans un composant non-top-level. |
